# Innhold

Nettstedet har to slags innhold: **innlegg**, som vises nyeste først og har kategorier og stikkord, og **sider**, som står for seg
selv (for eksempel «Om oss» og «Kontakt»). Begge skrives i den samme redigereren.

## Skrive

«Innlegg → Legg til nytt» eller «Sider → Legg til ny» åpner redigereren. Innholdet er bygd av **blokker**: avsnitt, overskrifter,
lister, bilder, gallerier, sitater, tabeller, knapper, innbygginger og flere. «Legg til blokk» (eller `/` i et tomt avsnitt) viser
blokkene, og hver blokk har sine egne innstillinger i sidepanelet. Lim du inn tekst med tomme linjer, blir hvert stykke et eget
avsnitt.

Sidepanelet har også innstillingene for hele dokumentet: status, synlighet, publiseringsdato, forfatter, kategorier og stikkord,
fremhevet bilde, utdrag og feltene for søk og deling.

Raskere: «Hurtigutkast» på kontrollpanelet lagrer en tittel og litt tekst som en kladd.

## Status og synlighet

| Status                | Betyr                                                                         |
| --------------------- | ----------------------------------------------------------------------------- |
| Kladd                 | Lagret, men ikke publisert.                                                   |
| Venter på gjennomgang | En bidragsyter har sendt det til en redaktør, som kan publisere det.          |
| Planlagt              | Publiseres av seg selv på tidspunktet du har valgt.                           |
| Publisert             | Synlig for alle.                                                              |
| Privat                | Synlig bare for redaktører og administratorer.                                |

**Passordbeskyttet** innhold er publisert, men leseren må skrive passordet for å se det. **Forhåndsvisning** viser den lagrede
versjonen slik den blir på nettstedet, også før den er publisert.

## Listene

«Alle innlegg» og «Alle sider» har filtre etter status, dato og kategori, søk og sortering. Hold pekeren over en tittel (eller bruk
tastaturet) for å redigere, hurtigredigere, flytte til papirkurven eller vise innholdet. Velger du flere rader, kan du endre dem
samlet. «Skjermalternativer» bestemmer kolonnene og hvor mange rader som vises; valget lagres for deg.

Innhold i papirkurven kan gjenopprettes. Slettes det derfra, er det borte.

## Kategorier og stikkord

«Innlegg → Kategorier» og «Innlegg → Stikkord». Kategorier kan ligge under hverandre, stikkord kan ikke. Et innlegg uten kategori
får standardkategorien fra «Innstillinger → Skriving».

## Hvem kan gjøre hva

| Rolle       | Kan                                                                           |
| ----------- | ----------------------------------------------------------------------------- |
| Bidragsyter | Skrive egne innlegg og sende dem til gjennomgang.                             |
| Forfatter   | Skrive, publisere og laste opp filer til egne innlegg.                        |
| Redaktør    | Alt innhold: også andres innlegg og alle sider.                               |
| Abonnent    | Lese og endre egen profil.                                                    |

Administratoren kan i tillegg endre innstillinger, utseende og brukere. Se [Brukere](brukere.md).
