# Brukerdokumentasjon

Denne dokumentasjonen er for deg som driver et nettsted med toascribe, enten du installerer det selv eller skriver og publiserer.
Knappen «Hjelp» øverst i administrasjonen åpner siden som hører til skjermen du står på.

**Drift**

- [Installasjon](installasjon.md): fra en tom server til et nettsted som kjører.
- [Oppdatering](oppdatering.md): ny versjon av toascribe.
- [Sikkerhetskopi](sikkerhetskopi.md): kopier, nøkler og gjenoppretting.

**Bruk**

- [Innhold](innhold.md): innlegg, sider, kategorier og stikkord.
- [Media](media.md): bilder og andre filer.
- [Menyer](menyer.md): navigasjonen på nettstedet.
- [Tema](tema.md): utseendet, «Tilpass» og globale sett.
- [Innstillinger](innstillinger.md): det som gjelder hele nettstedet.
- [Brukere](brukere.md): kontoer, roller, profil og applikasjonspassord.

For utviklere: API-et er beskrevet i [docs/API.md](../API.md), og gjenoppretting steg for steg i [docs/RESTORE.md](../RESTORE.md).
